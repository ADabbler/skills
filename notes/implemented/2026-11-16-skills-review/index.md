# 技能中文对照

Status: implemented

两项技能的完整中文对照，包含主文件及参考内容。英文技能供代理使用，中文内容供阅读和核对。

- [Prose Standard 中文版](prose-standard.zh.md)：文字完整性、表达质量、事实核对和会话痕迹处理。

英文入口：[Agent Notes](../../../skills/agent-notes/SKILL.md)、[Prose Standard](../../../skills/prose-standard/SKILL.md)。

核对范围见[验证范围](../2026-10-02-agent-notes-architecture.md#验证范围)。
